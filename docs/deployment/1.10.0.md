# AB Socks 1.10.0 deployment

1. Run `database/migrations/014_v1.10.0_admin_mailbox.sql` in phpMyAdmin.
2. Upload and extract `AB-Socks-v1.10.0-deploy.zip` into the existing web root.
3. Keep the live `config/config.php` unchanged; it is intentionally excluded from the package.
4. In Admin → حساب‌های ایمیل, add `info@absocks.ir`. Use IMAP `mail.absocks.ir:993` SSL and SMTP `mail.absocks.ir:587` STARTTLS unless the hosting panel specifies different values.
5. Verify the PHP IMAP extension is enabled. If it is unavailable, the inbox/read functionality cannot operate through the native IMAP client.
